# lava-aws

Typed `(deflava-resource …)` shapes for the AWS terraform provider, for the lava
suite. Sits on `lava-core`; the tatara equivalent of `pangea-aws`.

## Layout

```
providers/aws/                    # one .tlisp shape per resource
  _index.tlisp                    # catalog aggregator (deflava-provider :aws)
  aws_route53_zone.tlisp          # generated from the full hashicorp/aws 6.69.1 schema
  aws_route53_record.tlisp
  aws_acm_certificate.tlisp
  aws_acm_certificate_validation.tlisp
  aws_cloudfront_distribution.tlisp
  aws_vpc.tlisp …                 # older, short hand-kept subsets
src/lib.rs                        # on-disk integrity tests
```

The DNS and edge shapes are generated by `lava-forge` from the provider schema
(`terraform providers schema -json`). The other shapes are hand-kept subsets and
grow the same way.

## Consumer pattern

Load `providers/aws/<name>.tlisp` with `include_str!` or `std::fs::read_to_string`.
`lava-architectures` renders compositions over these shapes.
